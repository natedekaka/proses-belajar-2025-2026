#### **Uraian - Poin Jawaban**

1. **LAN, MAN, WAN** *(5 poin masing-masing)*
   - LAN: area terbatas (gedung), contoh: lab sekolah, kecepatan tinggi
   - MAN: satu kota, contoh: jaringan antar kantor kota, fiber/microwave
   - WAN: antar kota/negara, contoh: internet, leased line/satelit

2. **5 perangkat keras jaringan** *(3 poin masing-masing)*
   - Router: hubungkan jaringan berbeda, routing paket
   - Switch: hubungkan perangkat LAN, kirim data ke port tujuan
   - Access Point: konektivitas WiFi ke jaringan kabel
   - NIC: kartu antarmuka jaringan di perangkat
   - Kabel UTP: media transmisi kabel Ethernet

3. **Hub vs Switch** *(4 poin)*
   - Persamaan: sama-sama hubungkan perangkat LAN
   - Perbedaan: Hub broadcast ke semua port; Switch kirim hanya ke tujuan; Switch lebih efisien

4. **Keunggulan UTP vs Coaxial** *(3 poin)*
   - Lebih fleksibel dan mudah dipasang
   - Harga lebih ekonomis
   - Mendukung kecepatan tinggi (hingga 10 Gbps)

5. **Skema LAN 20 PC** *(4 poin)*
   - Router → Switch 24-port → 20 PC + Printer + Access Point
   - Semua terhubung via kabel UTP
   - Access Point menyediakan WiFi tambahan

#### **Uraian - Poin Jawaban**

1. **Enkripsi & pentingnya** *(4+3 poin)*
   - Enkripsi: ubah plaintext → ciphertext, hanya bisa dibaca dengan kunci dekripsi
   - Penting: cegah pencurian data, lindungi privasi, patuhi regulasi

2. **3 cara amankan WiFi** *(3 poin masing-masing)*
   - Gunakan enkripsi WPA2/WPA3
   - Ganti password default dengan password kuat
   - Nonaktifkan WPS dan remote admin yang tidak perlu

3. **Langkah koneksi WiFi** *(5 poin)*
   - Aktifkan adapter WiFi
   - Pilih SSID dari daftar jaringan
   - Masukkan password (case-sensitive)
   - Tunggu status "Connected"
   - Verifikasi dengan buka browser/ping

4. **Troubleshooting LAN** *(5 poin)*
   - Cek fisik: kabel, indikator LED
   - Cek driver NIC di Device Manager
   - Cek konfigurasi IP (DHCP/manual)
   - Uji ping loopback dan IP router
   - Restart komputer/adapter

5. **WiFi Open vs Password** *(4 poin)*
   - Open: siapa saja bisa connect, data plaintext, rawan sniffing
   - Password: akses terbatas, data terenkripsi (WPA2/3), lebih aman

### 🔹 Pengayaan *(Jawaban bersifat analitis, berikut panduan)*

1. **Rancang topologi 5 lab**
   - Gunakan topologi Star terpusat dengan Core Switch
   - Setiap lab punya Switch lokal terhubung ke Core
   - Tambahkan VLAN untuk segmentasi traffic
   - Sertakan Router untuk koneksi internet dan firewall

2. **IPv4 vs IPv6**
   - Panjang alamat: 32-bit vs 128-bit
   - Format: desimal vs heksadesimal
   - Konfigurasi: DHCP vs SLAAC
   - Keamanan: IPSec opsional vs terintegrasi

3. **Cara kerja WPA3**
   - SAE (Simultaneous Authentication of Equals) cegah brute-force
   - Forward Secrecy: kunci sesi unik per koneksi
   - Enkripsi 192-bit untuk enterprise
   - Proteksi downgrade attack

4. **Mesh: Kelebihan & Kekurangan**
   - ✅ Redundansi tinggi, skalabel, jangkauan luas
   - ❌ Biaya tinggi, konfigurasi kompleks, latensi multi-hop

5. **Studi kasus keamanan**
   - Kasus: kebocoran data via WiFi open
   - Analisis: tidak ada autentikasi, traffic tidak terenkripsi
   - Solusi: WPA3-Enterprise + RADIUS, VLAN segmentasi, firewall rule, edukasi pengguna
