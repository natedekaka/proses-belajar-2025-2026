# 19 Sumber Daya Linux & Command Line Terbaik yang Wajib Kamu Ketahui (Rekomendasi 2025!)

Halo teman-teman Linux enthusiast! Kalau kamu sedang belajar Linux dan command line, pasti sering merasa overwhelmed dengan banyaknya tools dan situs yang ada. Baru-baru ini saya nonton video YouTube yang super bermanfaat berjudul **"the 19 best Linux resources I know of, in 11 minutes"** dari channel yang membahas daftar sumber daya terbaik untuk belajar Linux dan CLI.

Video ini ringkas banget (cuma 11 menit) tapi isinya padat! Pembicara membagikan tools, situs wiki, script, dan tips yang sudah membantunya selama bertahun-tahun. Saya transkrip dan rangkum jadi materi mudah dibaca, lengkap dengan link resmi, biar kamu bisa simpan di blog atau bookmark untuk belajar ulang kapan saja.

**Sumber video asli:** [https://www.youtube.com/watch?v=Jllnhid7O7w](https://www.youtube.com/watch?v=Jllnhid7O7w)

### 1. Tools Rescue Sistem (Paling Penting untuk Darurat)
- **Super Grub2 Disk** → Bootable USB untuk memperbaiki GRUB yang rusak. Bisa scan dan boot OS secara manual.  
  Link: [https://www.supergrubdisk.org/super-grub2-disk/](https://www.supergrubdisk.org/super-grub2-disk/)
- **Rescatux** → Live USB rescue untuk Linux **dan** Windows (fix GRUB, reset password, check filesystem, dll).  
  Link: [https://www.supergrubdisk.org/rescatux/](https://www.supergrubdisk.org/rescatux/)

### 2. Koleksi Command Pipeline Keren
- **CommandLineFu** → Ribuan contoh command dan pipeline unik dari komunitas (misalnya nonton film di terminal atau query Wikipedia via DNS).  
  Link: [https://www.commandlinefu.com/](https://www.commandlinefu.com/)

### 3. Situs Belajar Linux Terlengkap
- **The Linux Documentation Project (TLDP)** → Semua guide dari beginner sampai advanced, man pages, bash scripting, dll. Bisa dibilang satu situs ini cukup untuk jadi pro!  
  Link: [https://tldp.org/](https://tldp.org/)

### 4. Wiki Distribusi Terbaik
- **Arch Wiki** (plus Gentoo Wiki & Debian Wiki) → Wiki terbaik untuk semua distro, bukan cuma Arch. Contoh: halaman FFmpeg super lengkap dengan contoh.  
  Link: [https://wiki.archlinux.org/](https://wiki.archlinux.org/)

### 5. Tools Command Line Praktis
- **wttr.in** → Cek cuaca langsung di terminal! `curl wttr.in` atau `curl wttr.in/Jakarta`.  
  Link: [https://wttr.in/](https://wttr.in/)
- **Pure SH Bible & Pure Bash Bible** → Cara melakukan tugas tanpa command eksternal (hanya pakai bash/sh murni). Bagus untuk belajar scripting.  
  Link: [https://github.com/dylanaraps/pure-sh-bible](https://github.com/dylanaraps/pure-sh-bible) & [https://github.com/dylanaraps/pure-bash-bible](https://github.com/dylanaraps/pure-bash-bible)
- **ShellCheck** → Linter untuk shell script, otomatis deteksi error dan best practices.  
  Link: [https://www.shellcheck.net/](https://www.shellcheck.net/)

### 6. Bootloader & Performance
- **Rod's Books (rodsbooks.com)** → Penjelasan UEFI vs BIOS yang mudah dipahami + info rEFInd bootloader (alternatif GRUB yang lebih stabil di beberapa motherboard).  
  Link: [https://www.rodsbooks.com/](https://www.rodsbooks.com/) & rEFInd: [https://www.rodsbooks.com/refind/](https://www.rodsbooks.com/refind/)
- **Brendan Gregg's Website** → Ahli performance Linux, banyak chart dan tools untuk benchmarking.  
  Link: [https://www.brendangregg.com/](https://www.brendangregg.com/)

### 7. Dokumentasi Offline & Ringkasan
- **Man Pages** → Dokumentasi resmi di sistemmu (`man zsh`, dll). Jangan lupa bagian "SEE ALSO".
- **TLDR Pages** → Ringkasan man page dengan contoh praktis (misalnya `tldr dd` biar nggak salah hapus disk).  
  Link: [https://tldr.sh/](https://tldr.sh/)
- **cheat.sh** → Cheat sheet langsung di terminal (`curl cheat.sh/tar`). Lebih lengkap dari tldr.  
  Link: [https://cheat.sh/](https://cheat.sh/)

### 8. Struktur Direktori Linux
- **Filesystem Hierarchy Standard** → Penjelasan resmi isi setiap folder di root (/bin, /etc, /var, dll).  
  Link: [https://refspecs.linuxfoundation.org/FHS_3.0/fhs/index.html](https://refspecs.linuxfoundation.org/FHS_3.0/fhs/index.html)

### 9. Belajar Command Line dengan Fun
- **OverTheWire Bandit** → Game SSH interaktif untuk latihan command line dan basic security. Mulai dari level mudah.  
  Link: [https://overthewire.org/wargames/bandit/](https://overthewire.org/wargames/bandit/)

### 10. Koleksi Resource Terbesar
- **Awesome Lists di GitHub** → Daftar list resource untuk hampir semua topik (ada awesome-linux, awesome-shell, dll).  
  Link: [https://github.com/sindresorhus/awesome](https://github.com/sindresorhus/awesome)
