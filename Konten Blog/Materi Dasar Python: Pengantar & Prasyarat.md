**Materi Dasar Python: Pengantar & Prasyarat**  

**1. Prasyarat Wajib Sebelum Belajar Python**  

Sebelum mengikuti materi ini, pastikan Anda telah menguasai:  
##### **a. Instalasi Aplikasi di Sistem Operasi**  
- **Windows**: Cara install/uninstall software.  
- **macOS/Linux**: Proses instalasi aplikasi via terminal atau GUI.  
- *Catatan*: Materi ini **tidak akan diajarkan** dalam kelas.  

##### **b. Penggunaan Terminal/Command Prompt**  
- **Windows**:  
  - Membuka Command Prompt (`cmd`).  
  - Perintah dasar: `cd` (pindah folder), `dir` (daftar file), `mkdir` (buat folder).  
- **macOS/Linux**:  
  - Membuka Terminal.  
  - Perintah dasar: `cd`, `ls`, `mkdir`.  
- *Catatan*: Harus sudah mahir navigasi folder via terminal.  



#### **2. Persiapan Awal untuk Peserta**  
1. **Instal Python**:  
   - Unduh di [python.org](https://python.org).  
   - Pilih versi stabil (contoh: Python 3.10+).  
   - Pastikan centang **"Add Python to PATH"** saat instalasi (Windows).  
   
2. **Verifikasi Instalasi**:  
   - Buka terminal/command prompt.  
   - Ketik: `python --version` atau `python3 --version`.  
   
3. **Siapkan Code Editor**:  
   - Rekomendasi: VS Code, PyCharm, atau Jupyter Notebook.  
   
   

#### **3. Tips Sukses Belajar Python**  
- **Praktik Langsung**: Ketik kode sendiri, jangan hanya copy-paste.  
- **Manfaatkan Sumber**:  
  - Dokumentasi resmi Python ([docs.python.org](https://docs.python.org)).  
  - Video tutorial di YouTube  
- **Tanyakan jika Bingung**:  
  - Gunakan grup Telegram atau kolom komentar kelas.  

### 
Materi ini adalah **langkah awal** sebelum masuk ke kode Python. Pastikan semua prasyarat terpenuhi agar tidak ketinggalan di sesi berikutnya. Setelah ini, Anda akan langsung mempelajari:  
- Sintaks dasar Python.  
- Tipe data, variabel, dan operator.  
- Control flow (percabangan & perulangan).
