**CAPAIAN PEMBELAJARAN INFORMATIKA FASE E**
Pada akhir fase E, peserta didik memahami konsep dasar Informatika dan perannya dalam kehidupan. Mereka mulai mengenalkan berpikir komputasional untuk memecah masalah sederhana. Peserta didik mampu mengidentifikasi komponen Teknologi Informasi dan Komunikasi (TIK) serta memahami cara kerja sistem komputer. Mereka juga mulai menyadari adanya etika dan dampak awal dari penggunaan teknologi.

**Fase E Berdasarkan Elemen**

| Elemen                                 | Capaian Pembelajaran                                         |
| :------------------------------------- | :----------------------------------------------------------- |
| **Pengantar Informatika**              | Di akhir fase E, peserta didik dapat menjelaskan pengertian Informatika, membedakannya dengan TIK, dan mengidentifikasi peran serta karir yang terkait dengan bidang ini. |
| **Berpikir Komputasional**             | Di akhir fase E, peserta didik dapat mengidentifikasi pilar-pilar berpikir komputasional (dekomposisi, pengenalan pola, abstraksi, algoritma) dan menerapkannya pada masalah sehari-hari yang sederhana. |
| **Teknologi Informasi dan Komunikasi** | Di akhir fase E, peserta didik dapat mengidentifikasi berbagai perangkat keras dan perangkat lunak TIK, serta menjelaskan fungsinya masing-masing. |
| **Sistem Komputer**                    | Di akhir fase E, peserta didik dapat mendeskripsikan komponen-komponen utama sistem komputer (perangkat keras, lunak, dan brainware) serta menjelaskan cara kerja dasarnya (proses input-proses-output). |

**CAPAIAN PEMBELAJARAN INFORMATIKA FASE E**
Pada akhir fase E, peserta didik dapat memahami konsep dasar jaringan komputer dan internet. Mereka mampu melakukan pengumpulan dan penyajian data sederhana. Peserta didik dapat menyusun algoritma dasar dan membuat program yang sangat sederhana. Mereka juga menyadari dampak sosial dari teknologi dan mampu menerapkan konsep Informatika dalam konteks lintas bidang ilmu.

**Fase E Berdasarkan Elemen**

| Elemen                                      | Capaian Pembelajaran                                         |
| :------------------------------------------ | :----------------------------------------------------------- |
| **Jaringan Komputer dan Internet**          | Di akhir fase E, peserta didik dapat menjelaskan manfaat jaringan, mengenali jenis-jenisnya (LAN, WAN), dan memahami konsep dasar internet dan penjelajahan web yang aman. |
| **Analisis Data dan Algoritma**             | Di akhir fase E, peserta didik dapat mengumpulkan data, menyajikannya dalam bentuk tabel dan grafik sederhana, serta menyusun algoritma dasar untuk memecahkan masalah terstruktur. |
| **Pemrograman Dasar**                       | Di akhir fase E, peserta didik dapat mengenal konsep variabel dan membuat program sederhana dengan menggunakan blok kode atau bahasa pemrograman tingkat dasar. |
| **Dampak Sosial dan Praktik Lintas Bidang** | Di akhir fase E, peserta didik dapat mengidentifikasi etika digital, keamanan siber, dan menerapkan pengetahuan Informatika untuk membantu penyelesaian tugas pada mata pelajaran lain. |
