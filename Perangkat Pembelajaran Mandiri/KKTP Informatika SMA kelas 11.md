**CAPAIAN PEMBELAJARAN INFORMATIKA FASE F**
Pada akhir fase F, peserta didik dapat menerapkan berpikir komputasional untuk memecah masalah, merancang algoritma, dan memprogram solusinya. Mereka mampu menganalisis dampak sosial, ekonomi, dan budaya dari teknologi informasi serta bertindak sebagai warga digital yang bertanggung jawab dan kritis.

**Fase F Berdasarkan Elemen**

| Elemen                                | Capaian Pembelajaran                                         |
| :------------------------------------ | :----------------------------------------------------------- |
| **Algoritma dan Pemrograman**         | Di akhir fase F, peserta didik dapat menerapkan berpikir komputasional (dekomposisi, pengenalan pola, abstraksi, algoritma) untuk merancang solusi masalah. Mereka dapat menyusun algoritma dengan notasi pseudocode atau flowchart dan mengimplementasikannya dalam bahasa pemrograman untuk membuat program sederhana. |
| **Berpikir Kritis dan Dampak Sosial** | Di akhir fase F, peserta didik dapat mengevaluasi keabsahan informasi di era digital untuk menghindari misinformasi. Mereka dapat menganalisis berbagai dampak positif dan negatif teknologi informasi serta menerapkan etika digital, privasi data, dan keamanan siber. |

**CAPAIAN PEMBELAJARAN INFORMATIKA FASE F**
Pada akhir fase F, peserta didik dapat memahami konsep dasar jaringan komputer dan internet. Mereka dapat mengembangkan aplikasi mobile sederhana dengan memanfaatkan library kecerdasan artifisial, serta melakukan proyek analisis data untuk menghasilkan informasi yang bermakna.

**Fase F Berdasarkan Elemen**

| Elemen                             | Capaian Pembelajaran                                         |
| :--------------------------------- | :----------------------------------------------------------- |
| **Jaringan Komputer dan Internet** | Di akhir fase F, peserta didik dapat menjelaskan konsep dasar jaringan (topologi, perangkat), cara kerja internet, dan protokol-protokol utama (HTTP, TCP/IP). Mereka juga memahami prinsip-prinsip keamanan jaringan. |
| **Pengembangan Aplikasi dan AI**   | Di akhir fase F, peserta didik dapat memahami tahapan pengembangan aplikasi mobile. Mereka dapat menggunakan library AI siap pakai (pre-trained model) untuk menambahkan fitur cerdas (seperti pengenalan gambar atau teks) pada aplikasi sederhana. |
| **Analisis Data**                  | Di akhir fase F, peserta didik dapat mengumpulkan, membersihkan, memvisualisasikan, dan menafsirkan data untuk menjawab pertanyaan penelitian sederhana. Mereka dapat menyajikan hasil analisis dalam bentuk laporan atau dashboard. |
